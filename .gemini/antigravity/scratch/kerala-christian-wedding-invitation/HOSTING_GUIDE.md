# 🚀 How to Host Your Wedding Website Online (100% Free)

Congratulations! Your Kerala Christian Wedding Invitation website is fully built and ready to go live. You can host it online and get a shareable link for WhatsApp within 5 minutes using any of the 3 free hosting methods below.

---

## Method 1: Netlify Drag-and-Drop (Easiest - 2 Minutes)

1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your web browser.
2. Drag and drop your project folder (`kerala-christian-wedding-invitation`) onto the Netlify webpage upload area.
3. Within 10 seconds, Netlify will generate a live public web link (e.g. `https://rohan-weds-sandra.netlify.app`).
4. You can edit the domain name anytime for free in Netlify Site Settings.

---

## Method 2: Vercel CLI / Web (Recommended for Speed)

### Option A: Via Vercel Web
1. Push your folder to a free [GitHub](https://github.com) repository.
2. Sign in to [Vercel.com](https://vercel.com) with GitHub.
3. Click **Add New Project**, select your repository, and click **Deploy**.
4. Your website will be live at `https://rohan-and-sandra.vercel.app`.

### Option B: Via Command Line (Vercel CLI)
Run the following command in your terminal inside the project directory:
```bash
npx vercel
```
Follow the 3 quick prompts to publish immediately!

---

## Method 3: GitHub Pages (100% Free Forever)

1. Create a public repository on GitHub (e.g., `wedding-invitation`).
2. Run these commands inside your project folder:
   ```bash
   git init
   git add .
   git commit -m "Kerala Christian Wedding Invitation Website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/wedding-invitation.git
   git push -u origin main
   ```
3. On GitHub, go to **Settings -> Pages**.
4. Under **Source**, select `main` branch and `/ (root)` folder, then click **Save**.
5. Your website will be published live at `https://YOUR_USERNAME.github.io/wedding-invitation/`.

## ✏️ How to Customize Couple Details & Photos

To edit any details (Couple names, wedding date, church location, family details, Google Maps links):
1. Open the `config.js` file in any text editor.
2. Update the text fields and save the file.
3. Re-upload or push to your hosting provider. The live site will update instantly!
